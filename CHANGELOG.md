# Changelog

## 2.0.0 — 2026-10-06

Added an installable Android/iPhone web app: 48 lessons and knowledge checks, device-local notes and review progress, backup/import, seven interactive JavaScript labs, install manifest/icons and offline caching. Numerical models and cache behavior have automated checks; physical-phone installation and layout have not been device-tested. No app-store release or native APK/IPA is included.

## 1.0.0 — 2026-10-06

Initial teaching package: 48 English lessons and worksheets, 12 phase guides, 24 quizzes/answer keys, seven computational labs, numerical tests, offline reader, bilingual onboarding, build plans, facilitator materials, project briefs and research boundaries.

Numerical verification and repository checks are available in this release. Physical builds and classroom delivery have not been validated. Source repository: https://github.com/freedomyamato/tensegrity-from-scratch.
