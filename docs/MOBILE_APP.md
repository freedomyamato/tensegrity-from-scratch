# Mobile learning app

**Open the app:** https://tensegrity-learn-mobile.toyspredator.chatgpt.site

The app is publicly accessible by link. Each person's progress and notes remain on their own device.

The app source is in [app/](../app/README.md). It turns the course into mobile lesson navigation, quizzes, a local notebook, progress backup/import and seven interactive labs.

Installation on Android: open the published URL in Chrome and choose Install app or Add to Home screen. Installation on iPhone: open in Safari, choose Share → Add to Home Screen, keeping Open as Web App enabled if shown. Browser wording varies by version. Wait for Ready offline before closing the first online session.

The app’s browser installation is separate from Play Store/App Store publication. No signed native binaries or store listings are included in this version. A future native wrapper or store submission would require platform build/signing and distribution setup.

Progress stays on each device. Export a backup before clearing browser data or switching phones. Offline availability depends on retaining the cached course; external research links still need the internet.

Primary platform references: [Apple: Turn a website into an app](https://support.apple.com/en-bh/guide/iphone/iphea86e5236/ios), [MDN: Making PWAs installable](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable), and [MDN: Service Worker API](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API). These describe platform behavior; they do not replace testing this app on actual target devices.
