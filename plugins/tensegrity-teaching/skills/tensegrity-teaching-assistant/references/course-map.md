# Course map
Source: https://github.com/freedomyamato/tensegrity-from-scratch/blob/main/COURSE.md
Read on 2026-10-07 Singapore time. The source has 48 lessons and 12 phases; estimated hours are planning allowances, not measured study times. Retrieve current content for exact lesson instructions.

| Phase | Lessons | Focus | Evidence of readiness |
|---|---|---|---|
| 00 | 01–04 | Goals, materials, measurement, safe notebook | Record an observation with units |
| 01 | 05–08 | Tension, compression, load paths, prestress, lookalikes | Label force roles and explain slack |
| 02 | 09–12 | Nodes, prism, twist, repeatable assembly | Verify connectivity and document joints |
| 03 | 13–16 | Vectors, free-body diagrams, equilibrium, self-stress | Explain balanced nodal forces |
| 04 | 17–20 | Stretch, buckling, slip, creep, inspection | Identify a failure observation and stop condition |
| 05 | 21–24 | Coordinates, equilibrium matrices, form-finding, validation | Separate ideal model from measurements |
| 06 | 25–28 | Vibration, recovery, wind, damage scenarios | Plan a controlled comparative experiment |
| 07 | 29–32 | Solar, rooftop, floating concepts, frame comparison | Identify confounds and engineering review needs |
| 08 | 33–36 | Measurement, calibration, controls, AI | Explain data quality and bounded adjustments |
| 09 | 37–40 | Accessible teaching, assembly inspection, facilitator practice | Use a chosen adaptation and document evidence |
| 10 | 41–44 | Residents, sculpture concepts, ownership, trial gates | Write a prototype brief with review gates |
| 11 | 45–48 | Baseline, tests, limitations, replication | Report evidence and a reproducible handover |

For a first lesson, use phases 00–01. For a first assembly, check these prerequisites before phase 02: identify cable/strut roles, recognize nodes, and follow joint checks. For experienced learners, use an observed task for placement instead of assuming prior mastery.
