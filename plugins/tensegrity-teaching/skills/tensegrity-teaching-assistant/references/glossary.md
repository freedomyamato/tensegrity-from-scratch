# English–Chinese teaching glossary

| English | Chinese | Plain explanation |
|---|---|---|
| Tensegrity | 张拉整体 | Prestressed tension network with compression members; clarify topology |
| Tension | 拉力 | A pulling force |
| Compression | 压力（压缩力） | A pushing force |
| Strut | 压杆 | A member designed to carry compression |
| Cable | 拉索 | A flexible tension member |
| Node | 节点 | Defined member attachment point |
| Prestress | 预应力 | Internal stress introduced before an added working load |
| Equilibrium | 平衡 | Balanced forces and moments |
| Slack | 松弛 | Cable not taut; a cable cannot push |
| Buckling | 屈曲 | Instability of a compressed member |
| Creep | 蠕变 | Time-dependent deformation |
| Load path | 传力路径 | Route by which forces pass through the structure |
| Form-finding | 找形 | Finding geometry compatible with structural constraints |
| Hypothesis | 假设 | A proposition to test, not a verified result |

Translate task instructions into short, concrete sentences. Preserve units and node labels. Do not translate an unverified hypothesis into a certainty.
