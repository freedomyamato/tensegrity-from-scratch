# Teaching playbook

## Lesson output
1. State audience, language, time and assumptions.
2. Give 2–3 observable objectives and prerequisite check.
3. List materials and facilitator preparation; offer a no-build alternative.
4. Provide a timed table: minutes, learner action, facilitator prompt, evidence.
5. Provide brief learner task cards in order.
6. Give an exit ticket, instructor answers and next activity.

Use predict → observe/build → measure → explain → revise. Prefer observations over appearance-based praise. Avoid requiring a stable first build as a condition of learning success: an honestly documented failure can demonstrate understanding.

## Quiz output
Default to five questions spanning identification, explanation and application. For each instructor answer give the correct response, reasoning, misconception and follow-up. Label point values before grading. Do not place answers beside learner questions unless the user asks for a study sheet. For practical tasks, assess evidence rather than speed alone.

## Progress rubric
Use 0 = observed but not yet demonstrated, 1 = partial, 2 = adequate explanation or task evidence, 3 = accurate evidence plus reasoning or repeatability. Use not observed when evidence is absent.
Assess: force-role understanding; connectivity/assembly; observation/measurement; explanation/reflection. Track support separately as independent, verbal prompt, visual prompt, physical assistance, or not recorded. A supported demonstration can still show sound understanding.
Compute average = sum of observed numeric ratings / number observed; report the coverage, such as 2 of 4 dimensions. If none observed, do not compute an average. Never use this local instructional rubric as a credential or clinical scale.

Progress note fields: anonymous learner ID; date; phase; task; observed evidence; dimension ratings; support; learner preference; next task. Preserve original evidence and label interpretations. Never infer that a missing upload means the learner failed.

## Accessible task cards
Use one action per card with a completion cue. Offer printed labels, large type, tactile or non-tactile choices, a quiet work area, breaks, pre-cut components and partner roles. Ask the learner which options help. Demonstration, verbal explanation, photos of a labelled model and diagram annotation can assess the same force-role objective. Do not impose touch, eye contact, group speaking or speed as evidence of understanding.

## Controlled experiment
Record question, baseline, variable changed, constants, measurements with units, repeats, deviations and limitations. Keep initial prism sessions unloaded. Do not invent stiffness, strength, load limits or missing readings. For solar mock-ups, compare geometry and shading before making generation claims; electrical-output comparisons require measured data and matched conditions.
