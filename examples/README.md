# Example data provenance

`solar_readings.csv` and `cable_extension.csv` are synthetic teaching datasets. They are not measured panel or material performance. The solar data represent simultaneous loaded readings only by assumption; real experiments must establish that acquisition condition.

To replace them, keep the required column names and SI units, preserve a private raw record and document instrument calibration, specimen, conditions and missing values. Never overwrite teaching examples with identifiable learner records in a public repository.
