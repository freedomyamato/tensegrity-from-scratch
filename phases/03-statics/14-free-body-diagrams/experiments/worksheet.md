# Lesson 14 worksheet

Topic: Free-body diagrams

## Before

Record date, specimen/activity ID, prediction and setup.

## During

- [ ] Draw boundaries for one member, one node and the whole model.
- [ ] At node 0, draw the four member directions using the supplied coordinates.
- [ ] Assign tensile arrows to cables and compressive arrows to the strut.
- [ ] Add external forces only for the physical supported case.
- [ ] Check whether any reaction has been assumed without a real support.

## After

Required evidence: Three free-body diagrams with a written sign convention.

Record raw observations, units, disagreements, support used and one next step. Do not invent missing data.
