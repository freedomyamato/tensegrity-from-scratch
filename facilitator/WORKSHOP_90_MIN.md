# First workshop: seeing the forces

Audience: a small group with supports selected in advance. Duration: approximately 90 minutes with flexible breaks. Objective: identify cable tension and strut compression and explain one model connection. This is a planned workshop, not a previously tested delivery.

## Prepare

One inspected low-tension prism per small group or one shared demonstration, blunt sticks, cord, sponge, printed node diagram, large labels, task cards, ruler, pencils and tray. Offer a drawing-only station and quiet workspace option. Preassembled models avoid tying-knots demands when the objective is force identification.

## Session

| Time | Activity | Evidence/check |
|---|---|---|
| 0–10 min | Preview sequence, choose response/support options | Learners know how to pause or request help |
| 10–20 min | Gently pull string and compress sponge | Correct tension/compression labels |
| 20–35 min | Observe prism and match node/member labels | Identify C0 and S0 by endpoints |
| 35–45 min | Break or quiet drawing activity | Support choices respected |
| 45–60 min | Draw one node’s connected members | Distinguish cables from strut |
| 60–75 min | Measure a span three times | Units, endpoints and readings recorded |
| 75–85 min | Teach back using speech, drawing or pointing | Explain one force and one measurement limit |
| 85–90 min | Feedback and close | One clarity comment and next activity |

Do not attempt a rushed complete prism build during the first conceptual session. If the group is ready, use the separate build procedure in a later making workshop.

## Questions and answers

1. Can string push? In the ideal flexible-cable model, no; it slackens.
2. Does the model use antigravity? No; forces transfer through members and external supports.
3. Does a small residual prove stability? No; it checks force equilibrium only.
4. Is one exact-looking number sufficient? No; show endpoint, units, instrument resolution and repeated readings.

## Review

Use the explanation and measurement rubric dimensions. Note whether learner goals were demonstrated with chosen supports. Retain a rehearsal label if this session was only practiced by the facilitator. Revise the sequence based on feedback before scheduling a wider pilot.
