# Evidence templates

Copy templates to a **private** notebook or the ignored `learner-data/` directory. Keep public source files free of names, diagnostic information and identifiable photographs. Blank template fields are intentional; fill them with your actual evidence, never invented data.

- [Experiment record](experiment.md)
- [Progress record](progress.md)
- [Bill of materials](bill-of-materials.csv)
- [Inspection log](inspection.csv)
- [Comparison table](comparison.csv)
- [Task card](task-card.md)
- [Facilitator observation](facilitator-observation.md)
- [Community brief](community-brief.md)
- [Site review](site-review.md)
- [Capstone report](capstone-report.md)

CSV files have headers only so they cannot be mistaken for measured results.
