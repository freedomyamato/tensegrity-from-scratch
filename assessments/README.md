# Assessment guide

Each lesson has three teach-back questions. Each phase quiz collects its twelve questions and has a separate facilitator answer key. These are formative checks: learners may use drawings, demonstrations or supported responses.

Read the relevant `phase-NN-quiz.md` before `phase-NN-answers.md`. Equivalent reasoning is accepted. Ask the learner to explain a changed example rather than memorizing the answer wording.

The [rubric](RUBRIC.md) evaluates explanation, reproducibility, measurement, reasoning and communication. A suggested phase gate is at least level 2 in every applicable dimension, with unresolved handling/measurement issues addressed. Mark nonapplicable dimensions explicitly; do not invent physical evidence for a calculation-only exercise.

An internal completion record may name route, demonstrated skills, evidence IDs and reviewer. It must not be labeled an accredited certificate or professional structural qualification.
