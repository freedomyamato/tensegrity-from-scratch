# 张拉整体：从零开始

这套课程以伊万的太阳能雕塑、社区参与及技能学习想法为主题。共有12个阶段、48节英文课。中文材料目前包括本入门指南及术语表；并非全部课程的中文翻译。

## 学习目标

先做出一个能够重复组装、标记清楚、解释受力及测量尺寸的三杆桌面模型，再研究太阳能支架、社区工作坊和维护。核心循环是：观察 → 解释 → 画图 → 计算 → 制作或模拟 → 测量 → 比较 → 记录 → 向别人说明。

“张拉整体”并不是反重力。拉索传递拉力，压杆承受压力；节点必须满足力的平衡。预应力、刚度、稳定性和承载能力是不同概念。数值模型满足平衡，并不代表实物已经安全或适合安装在屋顶。

## 如何开始

1. 解压文件并保留所有文件夹结构。
2. 用浏览器打开根目录的 `reader.html`，或阅读 [课程目录](https://github.com/freedomyamato/tensegrity-from-scratch/blob/main/COURSE.md)。
3. 从第01课开始，准备纸、笔和尺。
4. 初期使用轻巧、钝头的课堂材料；先做接头样本，不要大力拉紧弹性材料。
5. 每节课保留预测、步骤、原始读数、单位及局限；不知道的数值不要编造。

不会编程也可以完成初期课程。需要电脑计算时，Python 3.10或以上即可；本课程不需要额外Python软件包。从仓库根目录执行：

```bash
python3 -m tensegrity prism
```

这会生成六个节点、十二个构件的理想三杆模型。30°扭转角的示例具有一维自应力空间。结果不是实物承载能力证明。

## 适合你的路线

优先路线：基础制作 → 静力学 → 材料与接头 → 数字模型 → 动态反应 → 太阳能应用 → 无障碍教学 → 社区设计 → 毕业项目。最终项目是“一区一太阳能雕塑”的桌面原型与可重复工作坊。先使用轻质假太阳能板，再考虑低电压教学板。

对于自闭症学习者，提供可选择的支持：清楚的编号、分步骤图片、预切零件、定位夹具、安静空间及休息。让学习者以指认、画图或演示表达理解。应与本人及相关教育工作者一起选择方法，不以诊断推定所有人的需要。这是教学方案，不是治疗宣称。

## 证据与边界

记录应明确标注“实测”“计算”“示例数据”。课程总时数180小时是规划估计，尚未经过课堂验证。完整屋顶、公共雕塑、水上阵列及有人使用的结构需要专业设计和现场审批。“量子张拉整体”仅作为可选研究假说，不是已经成立的物理理论。
