# English–Chinese glossary

| English | 中文 | Course meaning |
|---|---|---|
| Tensegrity | 张拉整体 | Framework coupling tension and compression; state the definition used |
| Tension | 拉力 | Axial pulling action |
| Compression | 压力／压缩力 | Axial pushing action |
| Cable | 拉索 | Ideal tension-only flexible member |
| Strut | 压杆 | Compression member in the intended state |
| Node | 节点 | Ideal point joining member endpoints |
| Topology | 拓扑／连接关系 | Which nodes are connected |
| Geometry | 几何构型 | Coordinates and dimensions |
| Prestress | 预应力 | Initial internal force state |
| Self-stress | 自应力 | Internal forces balanced without external nodal load |
| Equilibrium | 平衡 | Balanced force and moment conditions |
| Stability | 稳定性 | Response to perturbations; not synonymous with equilibrium |
| Stiffness | 刚度 | Force change per displacement in a specified response |
| Strength | 强度 | Material/failure resistance, distinct from stiffness |
| Buckling | 屈曲 | Loss of a compressed member’s straight equilibrium configuration |
| Form-finding | 找形 | Seeking geometry satisfying specified constraints |
| Force density | 力密度 | Axial force divided by member length, N/m |
| Creep | 蠕变 | Time-dependent deformation under sustained load |
| Fatigue | 疲劳 | Damage associated with repeated loading |
| Damping | 阻尼 | Mechanical energy dissipation in motion |
| Verification | 验证计算实现 | Check implementation against equations/known results |
| Validation | 验证模型适用性 | Compare with independent physical evidence |
| Resolution | 分辨率 | Smallest readable measurement increment |
| Power | 功率 | Rate of energy transfer, W |
| Energy yield | 发电量／能量产出 | Energy over a specified interval, Wh |
| Hypothesis | 假说 | A proposed explanation open to testing and rejection |

Translations are explanatory course terminology. Use one convention consistently and define ambiguous words in context.
