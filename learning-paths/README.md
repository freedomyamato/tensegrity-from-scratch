# Choose a route

All routes use the same authored lessons. A omitted phase does not imply qualification in its subject. Complete prerequisites needed for your chosen activity and retain missing evidence explicitly.

| Route | Phases | Finish with |
|---|---|---|
| Solar sculpture builder — Ivan’s default | 0–7, 9–11 | Tabletop solar-support comparison and workshop |
| Community facilitator | 0–4, 9–11 | Simple model kit, task cards and facilitator practice |
| Workforce prototype technician | 0–6, 9–11 | Assembly, measurement, inspection and documentation portfolio |
| Robotics and adaptive structures | 0–6, 8, 11 | Digital feedback/response study; physical actuation is outside v1 |
| Research explorer | 0–6, 11, then optional research module | Reproducible mechanics investigation and precise hypothesis |
| Full core | 0–11 | Entire 48-lesson portfolio |

Phase 8 can be added later to the solar route. Teaching activities can start early on simple supported models; do not require advanced mathematics to begin facilitating basic tension/compression activities.
