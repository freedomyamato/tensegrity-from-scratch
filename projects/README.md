# Project briefs

Choose one capstone after the prerequisites. Each ends in traceable evidence and a replication attempt. No brief grants permission to build a full-scale installation.

| Project | Prerequisites | Main outcome |
|---|---|---|
| [Solar sculpture](SOLAR_SCULPTURE.md) | Phases 0–7, plus community/capstone lessons | Tabletop support versus conventional baseline |
| [Community learning kit](COMMUNITY_KIT.md) | Phases 0–4 and 9 | Repeatable accessible workshop and feedback |
| [Robotics study](ROBOTICS_STUDY.md) | Phases 0–6 and 8 | Mock control/response investigation without hardware |

Use [capstone report](../templates/capstone-report.md) and the course [rubric](../assessments/RUBRIC.md). A negative or inconclusive finding is acceptable when it is supported honestly.
